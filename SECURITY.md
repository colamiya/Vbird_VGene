# Security Policy

## Supported version

Security fixes are maintained on the default branch. Use the latest released build or the latest source from `main`.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/colamiya/Vbird_VGene/security/advisories/new). Do not open a public issue for credentials, sandbox escapes, denial-of-service vectors, or another exploitable condition.

Include reproduction steps, affected version or commit, expected impact, and any suggested mitigation. Avoid including real secrets or personal data.
