# Phase 1 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 VGene 从概念原型推进到可构建、可运行、可验证的本地 MVP。

**Architecture:** 第一阶段不做链上、分布式节点、真实商业分润。先固定本地桌面闭环：React/Tauri UI 发起配置和仿真，Rust 后端执行 Wasm DNA，前端稳定显示实体、统计、详情和复盘。

**Tech Stack:** React 18、Vite、TypeScript、Three.js、Tauri v2、Rust、Wasmtime、Ollama、NVML。

---

## Phase 1 Definition of Done

- `npm run build` 通过。
- `cd src-tauri; cargo check` 通过。
- `npm run tauri dev` 能进入 Splash、Config、Simulation、Review 主流程。
- LocalMock 模式无需 Ollama 即可演示完整流程。
- 非 LocalMock 模式的数据通道不再解析压缩数据出错。
- README/CHANGELOG 同步记录真实状态。

## File Responsibility Map

- `src/App.tsx`：应用阶段流转、Tauri command 调用、世界数据解析、统计面板。
- `src/components/Arena.tsx`：3D 实体群渲染、观察者干预点击。
- `src/components/PhylogeneticTree.tsx`：谱系树 3D/可视化。
- `src/components/SettingsModal.tsx`：配置保存与用户参数。
- `src-tauri/src/main.rs`：当前 Tauri command、仿真循环、日志、硬件信息集中入口。
- `src-tauri/src/evolution/wasm_runtime.rs`：Wasmtime 沙箱执行与验证。
- `src-tauri/src/evolution/mutation.rs`：LocalMock/Ollama 突变。
- `README.md`：稳定项目认知、命令、代码核验状态。
- `CHANGELOG.md`：追加式记录每次任务完成情况。

## Task 2: Fix World Binary Data Contract

**Files:**
- Modify: `src/App.tsx`
- Modify: `src-tauri/src/main.rs`
- Optional Create: `src/utils/worldBinary.ts`

- [ ] Step 1: Decide MVP contract.
  - MVP recommendation: return uncompressed raw binary from Rust until frontend decompression is added.
  - Rationale: correctness first; zstd can return after visual pipeline is stable.

- [ ] Step 2: Move binary parsing out of `App.tsx`.
  - If creating `src/utils/worldBinary.ts`, expose `parseWorldBinary(buffer: Uint8Array)`.
  - Entity record is 36 bytes: id, x, y, z, altruism, score, energy, toxin, generation.
  - Optional trailing stats are 12 bytes: entropy, avgScore, avgGeneration.

- [ ] Step 3: Update backend or frontend to match the chosen contract.
  - If backend raw: remove/feature-gate `zstd::encode_all` in `get_world_binary`.
  - If frontend compressed: add a decompressor dependency and decode before DataView.

- [ ] Step 4: Add a small parser test if test harness is available.
  - If no test harness exists, add manual verification notes to `CHANGELOG.md`.

- [ ] Step 5: Run verification.
  - Run: `npm run build`
  - Run: `cd src-tauri; cargo check`
  - Expected: both pass.
