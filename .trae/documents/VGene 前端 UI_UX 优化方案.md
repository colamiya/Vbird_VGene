## 1. 启动门户 (The Gateway)
- **【功能】**：增加“退出协议”与“版本摘要”。
- **【跳转】**：由启动页进入“创世实验室”。

## 2. 创世实验室 (The Mother Machine - Config)
- **【新增界面】**：独立页面，用于设定种群规模、变异激进率、熵增系数及获胜规则。
- **【自适应】**：采用响应式表单，支持多分辨率显示。

## 3. 上帝控制台 (The Aether Window - God Console)
- **【排版优化】**：采用“非重叠”分栏布局，确保 3D 渲染区在中央，侧边栏在两侧。
- **【新增功能】**：增加“进化阶梯”状态条；底部增加“神谕干预”与“资源降维”控制台。
- **【本地化】**：界面元素全面中文话，术语对照 README。

## 4. 逻辑体审计器 (Organism Auditor)
- **【新增界面】**：右侧抽屉式面板，实时提取个体的 WAT 汇编源码，展示能量、毒素、代际等 20+ 项进化定律指标。

## 5. 结果复盘与显示设置 (Review & Settings)
- **【新增界面】**：凤凰协议复盘页，展示存活曲线并支持“孢子”导出。
- **【设置增强】**：Settings 中增加窗口比例（16:9/21:9）、全屏切换及 Mock Mode 开关。

## 6. Mock Mode 仿真层
- **【逻辑实现】**：前端内置基于 README 定律的随机数据发生器，实现脱离后端的独立 UI 调试。
