## 修复 Cargo 配置文件编码问题

由于在 Windows 环境下使用 PowerShell 命令创建文件时，默认可能使用了 UTF-16LE 编码，导致 Cargo 无法识别并报错 `stream did not contain valid UTF-8`。

### 修复步骤：
1. **重写配置文件**：使用标准的 `Write` 工具重新写入 `src-tauri/.cargo/config.toml`，确保其强制使用 **UTF-8 (无 BOM)** 编码。
2. **保持配置内容**：内容依然保持为使用 USTC 镜像和 sparse 协议，以确保在中国大陆环境下的下载速度。

### 验证：
- 请你在本地再次运行 `npm run tauri dev`。如果编码修复成功，Cargo 将能够正常读取配置文件并开始编译。
