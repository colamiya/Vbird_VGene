# AetherGenesis (以太创世) 演化系统开发计划

## 1. 后端核心强化 (Rust/Tauri v2)
### 高性能沙箱与熵增逻辑
- **Wasmtime 优化**：启用 `consume_fuel` 机制。每一行指令执行都会消耗虚拟能量（熵增），迫使代码向极简演化。
- **异步变异队列**：将 `MutationEngine` 改为异步。使用 `tokio::spawn` 处理 Ollama API 调用，避免阻塞模拟主循环。
- **并行 ECS 处理**：利用 `Rayon` 对上千个实体进行并行状态更新和 Wasm 执行，确保 1000+ 实体下的高性能表现。

### 演化算法实现 (二十定律集成)
- **代谢毒素**：引入 `metabolic_toxin` 指标，低效或高耗能代码将积累毒素，加速生命体消亡。
- **善恶博弈模型**：实现实体碰撞时的博弈逻辑。根据 `altruism` 值决定是资源交换（蓝色/协同）还是掠夺（红色/竞争）。
- **计算引力场**：高效代码实体将吸引周围资源（虚拟能量），形成正向反馈。

## 2. 前端界面与交互 (React/Three.js)
### 创世之门 (The Genesis Gate)
- **配置中心**：实现启动配置界面，允许用户调整种群基数、变异激进率、Ollama 接口地址等。
- **视觉风格**：采用“赛博朋克/黑客帝国”质感，使用 Tailwind CSS 的玻璃拟态 (Glassmorphism) 和霓虹灯效果。

### 演化领域 (The Arena)
- **高性能渲染**：优化 Three.js `InstancedMesh`，添加 Bloom（辉光）特效。
- **实时交互**：支持点击粒子查看其生成的 WAT (Wasm Text) 源代码。
- **跃迁机制**：当平均科技等级达到阈值，触发粒子坍缩动画（Three.js 实现），场景平滑切换至新“维度”。

## 3. 技术集成与优化
- **通信协议**：定义更轻量级的 `get_world_state` 响应，仅传输位置、颜色和关键统计数据，DNA 仅在点击查看时按需拉取。
- **环境自适应**：完善 `detect_hardware` 逻辑，根据 GPU 性能动态调整 Three.js 的渲染质量（如开启/关闭 Bloom）。

## 4. 构建与部署
- 提供针对 Windows 11 优化的构建说明，确保 Tauri v2 的所有功能正常运行。
