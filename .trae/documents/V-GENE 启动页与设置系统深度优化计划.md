## V-GENE 启动页与设置系统深度优化方案

作为顶级玩家与超级开发，我们将针对 **GenesisGate (启动页)**、**SettingsModal (设置)** 以及 **MotherMachine (母亲机床)** 进行全方位的沉浸感与稳定性升级。

### 1. 启动页 (GenesisGate) - 沉浸感与实时反馈
*   **3D 神经背景**：引入基于 `react-three-fiber` 的低功耗粒子螺旋背景，模拟神经进化主题。
*   **全域无死角拖拽**：优化 `data-tauri-drag-region` 布局，确保 UI 间隙仍可平滑拖动窗口。
*   **实时硬件 HUD**：将“主机环境”改为实时轮询（CPU 占用、内存压力），增加微型折线图反馈。
*   **创世声明与音效**：增加打字机效果的世界观介绍，并集成赛博风格的微弱电子音效反馈。
*   **退出确认**：实现极简的“退出协议”二次确认弹窗，防止误触。

### 2. 设置系统 (Settings) - 鲁棒性与自动化
*   **Ollama 智能联动**：
    *   **预检功能**：点击保存前自动验证 Ollama API 连通性，异常时红光预警。
    *   **模型下拉列表**：自动调用 `/api/tags` 接口获取已安装模型，告别手动输入。
*   **分辨率防抖 (Debounce)**：对窗口尺寸调整增加 300ms 防抖，防止快速连点导致的渲染异常。
*   **一键恢复出厂**：增加“重置为默认值”按钮，解决参数调乱的痛点。
*   **Fidelity 视觉联动**：在 Ultra 模式下自动开启 `postprocessing` 的 Bloom 和 MSAA 抗锯齿。
*   **热更新标注**：在 UI 上明确标识哪些设置（如最大实体数）需要重启模拟才能生效。

### 3. 母亲机床 (MotherMachine) - 逻辑深度与反馈
*   **神谕预览 (Oracle Preview)**：在应用神谕生成的参数前，显示“当前 vs 神谕建议”的对比列表。
*   **环境视觉联动**：根据选择的 `EARTH` / `DEEP_SEA` / `SPACE` 环境，实时切换 UI 的强调色和背景色调。
*   **配置预设方案**：提供“经典”、“灾变”、“繁荣”等一键配置模板。
*   **启动进度条**：在点击“开始数字大爆炸”后，展示 Wasm 编译和种群初始化的真实百分比进度。

### 4. 架构级支持
*   **i18n 基础架构**：建立简单的多语言管理系统，支持全中文/全英文切换。
*   **日志导出系统**：增加“导出调试日志”功能，方便排查 Wasm 运行时的逻辑崩溃。
