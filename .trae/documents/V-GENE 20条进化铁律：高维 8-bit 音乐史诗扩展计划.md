# V-GENE 20条进化铁律：高维 8-bit 音乐史诗扩展计划

我将作为来自未来的高维代码大师，为 V-GENE 注入一套完整的“演化律动”系统。这不仅仅是背景音乐，更是 20 条数字化生命演化铁律的声学体现。

## 1. 核心设计：20 条进化铁律
我将设计 20 首各具特色的 8-bit 音轨，每一首对应一条生命演化法则：
*   **01. 熵增定律 (Entropy)**：充满噪声与微小失调，模拟无序的扩张。
*   **02. 适者生存 (Survival)**：极具竞争感的快速高低音交替。
*   **03. 基因突变 (Mutation)**：高频率的随机突变音符，打破常规旋律。
*   **04. 自然选择 (Selection)**：稳健、律动感极强的节拍，代表环境的筛选。
*   **... 以及其他 16 条法则**（包括红皇后假说、共生演化、生殖隔离、欧米伽点等）。

## 2. 音乐工程参数
*   **时长保证**：采用 140 BPM，每首音轨设定为 **192 个 16 分音符步进**（约 20.57 秒），满足“至少 20 秒”的要求。
*   **全域缝合**：所有音轨均基于 **D Dorian (D 调多利亚调式)** 开发。这种调式兼具小调的深邃与大调的科技感，确保无论哪两首音轨衔接，在调性和节奏上都能实现“默契衔接”。
*   **智能调度**：在每首（192 步）结束时，系统将通过算法随机决定是 **循环当前法则** 还是 **跃迁至下一条随机铁律**。

## 3. 技术优化方案
*   **重构合成引擎 (`src/utils/bgm.ts`)**：
    *   引入 `EvolutionLaw` 接口，通过函数式生成器实时产生 20 种不同的音色与旋律，避免硬编码海量数据。
    *   **随机突变逻辑**：在所有音轨的中间部分保留并增强随机音符生成，模拟演化过程中的不确定性。
*   **UI 反馈**：在 `App.tsx` 中增加当前正在播放的“进化铁律”名称显示（可选），增强沉浸感。

## 4. 交付标准
*   **详细注释**：为每一条铁律的代码块添加中文注释，解释其音频设计如何体现该演化法则。
*   **高性能**：依然保持 Web Audio API 实时合成，零外部资源引用。
