## 修复后端编译错误与警告

针对用户报告的 `wasmtime v41.0.0` 编译环境下的 Rust 错误和警告，我们将进行以下修复：

### 1. 修复 CPU 使用率获取错误 (Error E0599)
由于 `sysinfo` 库版本更新（v0.37.2），`System` 结构体的 API 发生了变化：
*   **问题**：代码中使用了已废弃或不存在的 `sys.global_cpu_info().cpu_usage()`。
*   **修复**：在 `sysinfo` v0.37 中，直接调用 `sys.global_cpu_usage()` 即可获得全局 CPU 使用率（返回 `f32`）。

### 2. 消除未使用的变量警告 (Warning)
*   **问题**：在 `simulation_loop` 中计算了 `avg_gen` 但未在后续逻辑中使用。
*   **修复**：将 `avg_gen` 重命名为 `_max_gen`（以 `_` 开头表示忽略），并修正其语义（实际上 fold 逻辑是在计算最大世代）。
