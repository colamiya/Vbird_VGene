要在 Windows 11 虚拟机上启动项目并看到效果，你需要按照以下步骤配置环境和运行指令。

## 1. 环境准备 (Windows 11 VM)

你需要在虚拟机中安装以下软件：
- **Node.js**: 建议安装 LTS 版本 (18.x 或更高)。
- **Rust**: 通过 [rustup.rs](https://rustup.rs/) 安装。安装时会提示安装 **Visual Studio Build Tools**，请务必勾选 **C++ build tools**。
- **WebView2**: Windows 11 通常自带，如果运行报错请手动下载安装。
- **Git**: 用于克隆或管理代码。

## 2. 启动指令

打开终端（PowerShell 或 CMD），进入项目根目录：

```powershell
# 1. 安装前端依赖
npm install

# 2. 启动开发模式（同时启动前端和 Tauri 后端）
npm run tauri dev
```
