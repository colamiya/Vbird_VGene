# AetherGenesis (以太创世) README 编写计划

## 1. 项目概述与定位
- **项目名称**：AetherGenesis (以太创世)
- **核心定位**：基于 Rust 与 Wasm 的高性能跨维度数字生命演化平台。
- **视觉风格**：赛博朋克 / 黑客帝国冷峻质感。

## 2. 核心技术栈说明
- **后端**：Tauri v2 (核心架构), Rust (高性能逻辑), Wasmtime (逻辑基因沙箱), Rayon (并行计算), Sysinfo (环境自适应)。
- **前端**：React, Three.js (1000+ 粒子渲染), Tailwind CSS (玻璃拟态 UI), Lucide React (图标库)。

## 3. 核心功能模块详述
- **环境自适应模块**：硬件性能检测与动态实体数调节。
- **主权引擎 (Sovereign Engine)**：基于 ECS 架构，Wasm 驱动的 DNA 逻辑与异步 AI 变异。
- **演化领域 (The Arena)**：高性能 3D 渲染，支持代码实时查看与 Bloom 特效。

## 4. 详细的未来开发计划 (Roadmap)
- **第一阶段：引擎深化 (The Core Refinement)**
    - 完善熵增损耗系统与代码效率评分。
    - 集成更复杂的宿主函数接口。
- **第二阶段：生态系统扩展 (Ecosystem Expansion)**
    - 引入多细胞演化逻辑与代谢毒素反馈。
    - 实现群体博弈论模型（善恶互动逻辑）。
- **第三阶段：星际跃迁 (The Interstellar Leap)**
    - 完善维度跳转与场景平滑切换动画。
    - 引入多维度资源竞争机制。
- **第四阶段：文明演化 (Civilization Horizon)**
    - 引入科技树系统与外交/掠夺逻辑。
    - 实现演化历史日志与谱系图可视化。
